## 0.2.0 — 2026-09-28 — Detailed delivery, OSS stack and implementation contracts

### Added

- Separate technology-stack/install-plan and free-resource/license-register documents with frontend/backend package groups, self-hosted services and cost boundaries.
- Separate user-flow, roles/permissions, frontend/backend alignment, reusable-component and state-management specifications.

- Seven expanded phase plans, P0–P6, with ordered steps, owners, deliverables, task mapping and acceptance gates.

### Changed

- Required infrastructure/software now uses free/open-source self-hosted services; Forgejo/Runner replaces mandatory GitHub CI and managed-cloud assumptions.
- CSS/browser-native motion replaces the earlier optional GSAP direction under the FOSS constraint.
- Master rules, architecture, security, operations, mobile, design, backlog and launch gates aligned with the new documents.
- React built-in local/action state selected; business data/permissions stay server-owned without a required global client store.

### Scope and verification

Documentation now contains 38 Markdown files. All 43 implementation tasks remain pending; no packages installed and no app scaffold/deployment created. Iconsax artifact rights and compatibility are not falsely marked as cleared. Final documentation link/structure/reference checks are recorded in the completed list.
